更好的迁移
就在你的手中。

KCU Migrator 是一款安卓上的 Minecraft Java 版迁移工具： 帮你把旧版本目录里的模组、配置、存档，搬到新版本目录，并按目标版本与加载器匹配可下载的适配文件。

下载 Release 查看源码

它支持哪些启动器

面向安卓上的 Java 版启动器，基岩版（Bedrock）不适用。

FCL（FoldCraftLauncher） Zalith Launcher PojavLauncher Amethyst HMCL-PE 澪-Ultimate 更多启动器持续适配中

它能做什么

以下是当前 Release 里实际有的功能，没有列出来的就是还没做。

跨版本迁移

选好「迁移前」与「迁移后」两个版本目录，填目标 MC 版本和加载器，扫描后生成迁移方案，勾选要搬的 mods / config / options.txt / 资源光影 / 存档，一键执行。

模组市场

Modrinth 与 CurseForge 聚合搜索，按版本号、加载器、分类筛选；没填 CurseForge Key 时自动走国内镜像。

模组管理

读取 jar 元数据显示图标、版本、作者；支持启用 / 禁用、批量操作与回收站，误删可以还原。

后台下载

模组下载走后台服务，支持并行数量调节与断点续传，进度在通知栏里看。

世界与区块编辑

浏览本地世界的 .mca 区块文件，调色板查看与改方块；NBT 读写基于 ViaNBT。

数据包生成器

内置 misode 适配版，137 个数据包 / 资源包生成器，离线可用，结果直接落到工作目录。

服务器面板

对接 Pterodactyl Client API，浏览服务器目录、检查模组更新；下载到本机需要手动确认。

离线翻译

模组简介与网页内容翻译用 Google ML Kit 离线模型（约 30 MB，装完后不联网）。

导出整合包

把当前实例导出为 mrpack 格式，方便在别的启动器里直接导入。

怎么用

四步完成一次迁移。

从 Release 下载正式版 APK 安装。打开后先到「设置 → 存储」选一个工作目录（导出包、下载缓存、备份都放这里）。

回到「迁移」页：选「迁移前的版本」目录（里面有 mods 文件夹那个），再选「迁移后的版本」目录。

填目标 MC 版本号与加载器（Forge / Fabric / NeoForge / Quilt 等），点「扫描」，等它生成迁移方案。

勾选要迁移的内容，点「开始迁移」。失败的项可以单独重试。

隐私

代码里不含任何凭据。无账号体系也能用，无统计、无广告。

  • GitHub 登录只用于把备份传到你自己的私有仓库，不登录也能正常用。
  • CurseForge 请求默认走官方自己的后端代理；你也可以在设置里关掉后端、改用自己的 Key 直连，或完全离线。
  • 对联网敏感的话，设置里可以逐项关掉搜索 / 翻译 / 资讯 / 更新检查，或开「完全离线」总开关。
  • 卸载 App 会删掉本机数据；工作目录里你自己选的文件不会动。
